What it is

A search box over your own files. You ask in plain words; it answers from your documents. The technical name is retrieval-augmented generation (RAG): the AI looks things up in your files before it answers.

  1. Read. It reads manuals, SOPs, specs, job files and policies.
  2. Find. For each question, it pulls the few passages that match.
  3. Answer. It writes a short answer from those passages only.
  4. Cite. It links each answer to the page it came from.

Worked example of a sourced answer

Suppose an operator asks which freight terms apply to a customer order. A useful answer identifies the terms and links to the current agreement and its page. The operator can open that source and check it before acting.

If an old email conflicts with the agreement, the search should expose that conflict for review. If the agreement is absent or the operator cannot access it, the answer should say the available files do not establish the terms. This example illustrates the access and evidence checks to test, not a completed client deployment.

Where to start

  1. Pick a team. The one that asks the same questions every day.
  2. Collect 30 real questions. With the right answer and where it lives.
  3. Clean one folder. Current versions only, scans made readable.
  4. Test against the 30. Count right, wrong and "not found".
  5. Widen. Add sources and teams once the first set holds.

The test questions are the spec. If it can't answer them, it isn't ready.
