What job shop scheduling has to handle

  • High mix, low volume. Every job has its own routing.
  • Setups that change with the job order on each machine.
  • Outside processing that leaves the building and comes back late.
  • Material, fixtures and programs that aren't ready when the machine is.
  • Hot jobs that jump the queue.

Any tool that ignores these gets ignored by the floor.

Machine shop scheduling in Excel

A workable board has one row per operation, not per job:

  • Job, operation, machine, setup hours, run hours.
  • Due date and the date the material arrives.
  • Status: waiting, running, at vendor, done.
  • Sort by machine, then by priority.

It breaks when the board is a day behind the floor. See how to replace a spreadsheet workflow.

Check the ERP module first

Most shop ERPs include scheduling. JobBOSS², for one, lists drag-and-drop shop-floor scheduling, and Fulcrum lists an automatic scheduler (vendor websites, October 2026). Before buying anything new, ask:

  1. Is it switched on? Many shops own a module they never set up.
  2. Is floor data fresh? A schedule is only as good as job status.
  3. Does it know your rules? Setup groups, machine limits, who can run what.

A custom schedule on top of what you keep

  1. Read. Jobs, routings and due dates from the ERP.
  2. Capture. Start, stop and done from a tablet at the machine.
  3. Plan. Apply your rules: group setups, hold jobs missing material or programs.
  4. Show. One board per machine for the floor; late jobs flagged for the office.
  5. Write back. Status and actual hours return to the ERP.
